Đọc truyện trực tiếp từ máy tính, không cần upload, không cần server.

Trên điện thoại, mở/tạo thư mục trên máy không được hỗ trợ tốt — dùng Google Drive để đọc mượt hơn nhiều.
Cách hoạt động

Panelo đọc thẳng ảnh từ thư mục trên máy bạn (hoặc Google Drive) — không tải lên đâu cả, không cần tài khoản.

  1. Lần đầu dùng: bấm Khởi tạo thư viện và chọn một thư mục trống — app tự tạo sẵn cấu trúc mẫu. Lần sau chỉ cần bấm để mở lại. (Trên điện thoại thì bỏ qua bước này — dùng Google Drive ở bước 3 luôn cho gọn.)
  2. Mỗi truyện là một thư mục, bên trong gồm ảnh bìa và các thư mục chapter (mỗi chapter chứa ảnh, đặt tên theo số thứ tự để đọc đúng thứ tự).
  3. Muốn đọc từ Google Drive thay vì máy tính? Bấm . Thư viện đặt tên thư mục khác đi? Bấm để tuỳ chỉnh.

Kết nối Google Drive

Đọc thư viện từ thư mục Google Drive đã chia sẻ công khai — không cần đăng nhập, không cần lấy link từng ảnh.

  1. Vào Google Cloud Console, tạo project, bật Google Drive API (muốn dùng Sheet cho phần mô tả bên dưới thì bật thêm Sheets API luôn, cùng project).
  2. Vào Credentials → Create credentials → chọn API key (không cần OAuth).
  3. Chia sẻ thư mục truyện trên Drive ở chế độ "Bất kỳ ai có đường liên kết – Người xem", bấm Copy link, dán thẳng vào ô "Thư mục Drive" bên dưới — không cần tự cắt ID.

Sheet cần cột: folder, title, alternativetitle, author, artist, status, genres, description (folder trùng tên thư mục truyện), chia sẻ công khai giống thư mục Drive ở trên.

API key chỉ lưu trên trình duyệt bạn, nhưng hiện trong mã nguồn trang nên chỉ dùng cho thư viện đã công khai. Key bị giới hạn theo API thì nhớ tick cả Drive API lẫn Sheets API.

Cấu trúc thư mục

Cấu trúc: (thư mục cha) / Tên truyện / (ảnh bìa) + (chapter). Để trống ô nào = cấp đó không tồn tại, dùng luôn thư mục truyện cho phần đó.

Tên thư mục chapter không cần đúng dạng "Chapter N" — app tự sắp theo thứ tự tự nhiên. Có thêm cấp trung gian thì nối bằng /, ví dụ Extra/Type. Tên file ảnh bìa (thumbnail.jpg/.png/...) giữ nguyên như cũ.

Backup dữ liệu

Gộp toàn bộ cấu hình — API key, cấu trúc thư mục, giao diện, ảnh nền, yêu thích, tiến độ đọc, đã đọc từng chapter — thành 1 file duy nhất, để lưu dự phòng hoặc chuyển sang máy/trình duyệt khác.

Nhập file backup sẽ ghi đè toàn bộ cấu hình hiện tại trên trình duyệt này. Ảnh truyện thật không nằm trong file backup (vẫn ở máy/Drive của bạn) — sau khi nhập, bạn cần chọn lại thư mục/kết nối Drive như bình thường (trình duyệt không cho lưu quyền truy cập thư mục qua file được).
